01 · TODAY'S ALGORITHM

今日のアルゴリズム

今日はグリッドへの反復描画を体験します。画面を等間隔のマスに分け、それぞれに同じ手順をくり返すと、ひとつのルールから模様が生まれます。

何ができる？

タイル模様、ポスターの下地、規則と揺らぎを組み合わせた抽象画。

前提知識

画面に横と縦の位置があること。足し算と掛け算だけで大丈夫。

前回とのつながり

第1回なので、ここが出発点。次回は「場所によって違うルール」へ進みます。

02 · FIRST, AN EVERYDAY IMAGE

コピー機で、同じスタンプを押す。

便せんに小さなスタンプを押す場面を想像してください。紙の左上から始めて、横へ一定の間隔で押す。端まで来たら一段下がり、また横へ押す。これだけで、スタンプの模様が面いっぱいに広がります。

プログラムの「くり返し」は、この手作業をコンピューターに任せる仕組みです。今回のルールはシンプルです。

RULE / 01

「マスの中心に、少し小さな四角を描く」

これを、すべてのマスで行う。

03 · A SMALL NUMBER EXAMPLE

数を入れて、位置と揺れ幅をたしかめる。

デモのマス目を横12列にしてみましょう。キャンバスの横幅を360ピクセルとすると、1マスは幅を12等分した大きさです。

1マスの幅360 ÷ 12 = 30 ピクセル
2列目の左端列番号 1 × 30 = 30 ピクセル
そのマスの中心30 + 30 ÷ 2 = 45 ピクセル
四角の大きさ（58%）30 × 0.58 = 17.4 ピクセル
ゆらぎ40%の移動幅30 × 0.40 × 0.45 = 全幅5.4ピクセル
中心から動く距離(乱数 − 0.5) は −0.5〜+0.5 → 最大 ±2.7ピクセル
左から2列目の四角の中心は、揺らぎ0%なら横45ピクセルです。40%なら中心から最大2.7ピクセル動けます。シードを固定すると、その動きも同じ配置に戻せます。

「乱数 − 0.5」は、0から1までの乱数の真ん中を0へ移し、左右どちらにも同じ幅だけ動けるようにします。「× 0.45」は、マスを越えて図形がぶつからないよう、移動量に上限をつけています。

HOW THE RULE BECOMES CODEJavaScript
// rows と cols の回数だけ、同じ処理をくり返す
for (let row = 0; row < rows; row++) {
  for (let col = 0; col < cols; col++) {
    const x = col * cellWidth + cellWidth / 2;
    const y = row * cellHeight + cellHeight / 2;
    const shiftX = (random() - 0.5) * cellWidth * (chance / 100) * 0.45;
    drawShape(x + shiftX, y, cellWidth * size);
  }
}

コードの row と col は「何段目」「何列目」かを数える札です。 x と y は描く場所、 size は図形の大きさ、 chance はゆらぎの割合（0〜100）です。 random() は固定シードから作る0〜1の数で、スライダーを動かすと揺れ幅が変わります。デモでは同じ仕組みを縦方向や角度にも使っています。

04 · EXPERIMENT · 10–15 MIN

少しずつ、ルールを崩す。

デモを開き、まず規則的な状態を観察してから、ひとつずつ変化を加えましょう。

  1. 01 · 観察する

    ゆらぎが0%のまま、四角の間隔と余白を眺めます。すべて同じ位置に同じ形があるため、目は整ったリズムを感じます。

  2. 02 · 1つだけ変える

    「ゆらぎ」を15%まで上げます。位置や角度が少しずつ変わるのに気づくでしょう。ルールは残ったまま、きっちりした秩序がほぐれます。

  3. 03 · 端まで試す

    ゆらぎを100%にします。マスという骨組みは続いていますが、形が自由に動きます。変化が大きすぎると、格子の気配はどこまで残るでしょう。

  4. 04 · 別の絵をつくる

    ゆらぎを30%に戻し、ランダムシードを変えます。ゆらぎの量は同じでも、図形の揺れ方が別の配置になります。同じシードへ戻せば再現できます。

  5. 05 · 自分のルールにする

    図形を円やひし形に変え、行数と配色も選びます。「端の行だけゆらぎを強める」など、コードのルールをひとつ改造して、PNGで保存しましょう。

観察のヒント

ゆらぎを増やしたとき、目線はどこへ向かう？　シードを変えたとき、絵の雰囲気はどう違う？　正解はありません。変化を見つけることが今日の練習です。

05 · ARTIST & WORK

Vera Molnár — Interruptions

アーティストのヴェラ・モルナールは、コンピューターを使う以前から「イマジナリー・マシン」と呼ぶ手順を考え、幾何学的な形に少しずつ変化を加えていました。トレド美術館の解説では、1968年に始まった《Interruptions》について、25×25の格子に並ぶ線へランダムな回転や「途切れ」を加えたと紹介しています。

今日のデモはこの作品を再現したものではありません。規則的な格子に小さな違いを足し、秩序と偶然を行き来する考え方を学ぶための学習用の例です。作品を見るときは、整った並びがどこで乱れ、空白がどんなリズムを生んでいるか観察してみましょう。

06 · KEEP EXPLORING

次回は「条件」で変化をつける。

今日の絵は、すべてのマスに同じ図形を置きました。次回は「列の番号が偶数なら円、奇数なら四角」のように、位置に応じてルールを切り替えます。同じ格子を土台に、条件分岐で模様の語彙を増やしましょう。
